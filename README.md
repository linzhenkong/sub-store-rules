# Sub-Store 节点清洗与过滤规则

个人自用的 Sub-Store 远程 JavaScript 过滤与清洗脚本，用于自动剔除广告、无效节点、超高延迟节点以及回国/IPv6节点。

## 🛠️ 脚本功能
- **去广告与垃圾过滤**：精准剔除名称中包含电报群、推广、过期、测速失败等杂音节点。
- **IPv6 过滤**：自动识别并排除纯 IPv6 节点。
- **延迟过滤**：自动剔除测速异常或延迟大于 400ms 的节点。
- **回国过滤**：一键清除“回国”、“大陆专用”等无用节点。

## 🚀 如何在 Sub-Store 中使用

1. 复制你的 `filter.js` 文件的 **Raw 原始链接**。
2. 在 Sub-Store 的操作配置中，选择 **远程链接** 并粘贴该链接即可。
